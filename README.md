# Mahan Asgari — Personal Portfolio

Personal website of **Mahan Asgari**, Data Developer & Analyst.

**Live site:** [https://mahanasgari.ir](https://mahanasgari.ir)

## About

Static portfolio showcasing experience in data warehousing, ETL/ELT pipelines, BI dashboards (Power BI, Tableau, Metabase, Superset), Python backend work, and cloud/DevOps.

## Stack

- HTML, CSS, JavaScript
- Served with nginx + HTTPS (Let's Encrypt)
- SEO: `robots.txt`, `sitemap.xml`, Open Graph / Twitter Card tags, JSON-LD Person schema

## Local preview

```bash
# from repo root
python3 -m http.server 8080
# open http://localhost:8080
```
